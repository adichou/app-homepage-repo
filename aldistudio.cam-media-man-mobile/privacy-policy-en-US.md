# CamMan ZhuShou Privacy Policy

Last updated: August 29, 2026

CamMan ZhuShou respects user privacy. This policy explains how the app handles information on iPhone and iPad.

## The developer does not collect data

CamMan ZhuShou requires no registration or sign-in, contains no advertising or third-party analytics SDK, and does not send the user's photos, video, files, tags, ratings, location, device identifiers, diagnostics, or usage data to a developer-operated server.

## Data processed locally

To provide media ingest and shooting-reference library features, the app may process the following on the device or in storage selected by the user:

- Photos, video, and files explicitly selected by the user;
- Camera-card, external-storage, or folder names and file information;
- Reference tags, photo ratings, export settings, progress, and reports;
- File sizes or cryptographic digests needed for local integrity checks;

This information is used to complete user-initiated actions and is not remotely collected by the developer.

## Photos

When the user imports from Photos, the app requests system photo-library access to read original resources. Only assets whose required resources match completed exports are included in a deletion request made through Apple's system API. iOS displays the confirmation, and removed originals remain recoverable in Recently Deleted for the system retention period.

Saving through system sharing may require permission to add photos.

## Files and external storage

The app accesses only folders or volumes explicitly selected with the system file picker. Media transfer, verification, retransfer, and external-source cleanup are initiated by the user. Connected storage should remain attached until the operation completes.

## URLs entered by the user

The reference feature lets a user enter an HTTPS webpage to discover and import images. The request goes directly from the user's device to the third-party website and does not pass through a developer server. That website may receive the IP address, request time, device-network information, or other information necessary to serve the request, subject to its own privacy policy.

Users should import only content they own, are authorized to use, or may lawfully use.

## Retention and deletion

Local data remains in the app sandbox, Photos, or user-selected storage until the user removes it through the app, Photos, Files, or system settings. Uninstalling the app removes its sandbox data but does not delete media already exported to external or other user-selected storage.

Because the developer operates no account or remote user database, there is no server-side personal data for the developer to access, correct, or delete on request.

## Children's privacy

The app does not collect personal information from children and provides no social feed, chat, advertising, or public content distribution.

## Changes

If the app's data practices change, this policy and the App Store privacy disclosure will be updated as applicable.
