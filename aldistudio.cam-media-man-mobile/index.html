支持

导出前准备

  • 完整的相机卡流程需要源卡和可写入的目标存储，通常通过兼容的 USB-C 集线器同时连接。
  • 导出和源文件清理完成前，请保持两个设备连接。
  • 首次使用建议开启“测试模式”，先用 10 个文件验证流程。

为什么“开始导出”不可用？

请先选择有效的相机卡或照片图库来源，再选择可写入的目标目录。源卡与目标目录不能位于同一存储卷。

导出中断后怎么办？

重新打开 App 查看报告。失败或未完成的源文件会保留；可按报告处理同名冲突、重试失败项目或检查残留。

Support

Before an ingest

  • A full camera-card workflow requires a source card and writable destination storage, usually connected through a compatible USB-C hub.
  • Keep both devices connected until ingest and source cleanup are complete.
  • For a first run, enable Test Mode to validate the workflow with 10 files.

Why is Start Export unavailable?

Choose a valid camera-card or Photos source and a writable destination folder. The source and destination cannot be on the same storage volume.

What should I do after an interrupted ingest?

Open the app and review the report. Failed or unfinished source files remain in place. Use the report to resolve name conflicts, retry failed items, or inspect remaining files.

Contact support

The public support channel is GitHub Issues.

Include the app version, device model, system version, steps, and visible error. Do not upload private photos or sensitive files unless necessary and safe.

隐私政策

开发者不收集数据

CamMan 助手不要求注册或登录，不包含广告或第三方分析 SDK，也不会把照片、视频、文件、标签、评分、位置、设备标识符、诊断信息或使用数据发送到开发者运营的服务器。

本地处理

App 可能在设备本地或用户选择的存储位置处理用户主动选择的媒体、相机卡与目录信息、参考图标签、评分、导出配置、进度与报告，以及本地完整性检查所需的文件大小或散列值。

照片、文件与外置存储

App 仅访问用户通过系统界面明确选择的照片、文件夹或存储卷。照片图库原件的移除需要 iOS 系统确认，移除后仍可在“最近删除”中恢复。外置源文件清理由用户发起；目标副本复核失败时，对应源文件会保留。

用户输入的网址

参考图功能可直接访问用户输入的 HTTPS 网页以发现图片。请求从设备直接发往第三方网站，不经过开发者服务器。第三方网站可能按其隐私政策接收正常网络请求信息。

保留、删除与联系

本地数据保留在 App 沙盒、照片图库或用户选择的位置，直到用户通过 App、照片 App、文件 App 或系统设置删除。卸载 App 不会自动删除已导出到外置存储的文件。隐私问题可通过 GitHub Issues 联系。

Privacy Policy

Last updated: August 28, 2026

Read the full English Privacy Policy

The developer does not collect data

CamMan ZhuShou requires no registration or sign-in, contains no advertising or third-party analytics SDK, and does not send photos, video, files, tags, ratings, location, device identifiers, diagnostics, or usage data to a developer-operated server.

Local processing

The app may process user-selected media, camera-card and folder information, reference tags, ratings, export settings, progress, reports, and file sizes or digests required for local integrity checks on the device or in user-selected storage.

Photos, files, and external storage

The app accesses only photos, folders, or storage volumes explicitly selected through system interfaces. Removing Photos originals requires an iOS confirmation, and items remain recoverable in Recently Deleted. External-source cleanup is user initiated; if a destination recheck fails, the corresponding source file is retained.

URLs entered by the user

The reference feature may connect directly to an HTTPS webpage entered by the user to discover images. Requests go from the device to the third-party website and do not pass through a developer server. The website may receive ordinary network-request information under its own privacy policy.

Retention, deletion, and contact

Local data remains in the app sandbox, Photos, or user-selected storage until removed through the app, Photos, Files, or system settings. Uninstalling the app does not delete media exported to external storage. For privacy questions, use GitHub Issues.
