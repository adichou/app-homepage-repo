# How to download

- The app is a free download on the App Store. Note that it is not listed in the EU App Store — EU users can switch to another regional App Store.
- The free version is fully functional, with a limit of 1,000 exported photos per run (manual repeats allowed) and 100 imported reference photos. Pro removes the limits — see pricing in the app.

## Before an ingest

- A full camera-card workflow requires a source card and writable destination storage, usually connected through a compatible USB-C hub.
- Keep both devices connected until the ingest and any source cleanup are complete.
- For a first run, enable Test Mode to validate the workflow with 10 files.
- Large ingests can take a while — make sure your device has enough battery.

## Source protection

- The app copies media and checks the destination copy.
- Failed, incomplete, or conflicting items remain at the source.
- Before cleaning an external source, the app rechecks each destination file. If the recheck fails, the corresponding source file is retained.
- Removing originals from Photos requires an iOS confirmation, and removed items remain recoverable in Recently Deleted.

## Starting an ingest

1. Choose a source: a camera card or the Photos library.
2. Choose a writable destination folder. Note: the source card and destination cannot be on the same storage volume, otherwise Start Export stays unavailable.
3. (Optional) Enable Test Mode to validate the workflow with a few files.
4. Start the ingest and wait for the copy, verification, and report to finish.

## After an interrupted ingest

Open the app and review the report. Unfinished or failed source items stay in place. Follow the report to retry failed items, resolve name conflicts, or inspect remaining files.

## Importing reference images from the web

Shooting References supports importing images from Photos, Files, or an HTTPS webpage you enter, organized with tags for composition, lighting, color, location, and style.

If web import finds no images, enter a valid HTTPS webpage. Some sites block automated access, require sign-in, or render images only with dynamic scripts, so the app may not be able to extract candidates.
