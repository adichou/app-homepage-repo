# App Homepage Repository

这个仓库只存放需要公开发布的 App 官网材料，包括产品主页、隐私政策、支持页面和使用条款。

App Store Connect 元信息、审核备注、审核截图、订阅配置和发布检查清单不放在这里；这些材料保存在私有的 `app-info-repo`。App 源代码保存在各自的源码仓库。
